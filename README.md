## 开发运行

需要 Python 3.12 和可用的 Tkinter/Tcl/Tk 环境。

```sh
python -m pip install -r requirements.txt
python main.py
```

```sh
python -m pip install -r requirements-dev.txt

python -m mypy camtool main.py build_app.py --check-untyped-defs
```

## 第一次使用

1. 打开程序，保留演示项目，点击“计算设计”。
2. 依次查看“场地与试跑”“凸轮轮廓”“机构运动”“计算曲线”和“检查报告”；“同步演示”同屏观看路线、旋转凸轮和转向机构，统一理论时间轴支持倍率、暂停和拖动。
3. 新建自己的项目，填写实车尺寸、机构尺寸、打卡点和场地设置。打卡点按表格行序访问；CSV 为两列 x,y，可含表头。
4. 点击计算，在“问题定位”点击检查项查看位置、实际值、限值和依据。“本地优化”搜索路线张力和局部切线；原方案保留，在“优化对比”显式选择原方案或候选，没有改善时如实显示。
5. 保存项目。导出时建议选一个新的空目录，输出 DXF、两份 CSV、检查报告及项目快照。

尺寸均为毫米。示例尺寸不是 YDI 标准件的已核定尺寸，正式设计前必须测量并替换。当前模型需与实物一致后才可用于制作；软件没有自动读取 STEP 装配。

1.2.0 增加地图点击/拖动打卡点、撤销/重做、基础/高级参数分组、尺寸示意高亮和参数配置保存/加载；“实测与扰动”可导入明确单位/坐标/来源的传感器 CSV，以及在固定最终 DXF 上扫描驱动轮径和安装相位。模板只有格式，没有实测采样点；预测始终标为理论。设计和分析在后台执行，可取消，改参后旧结果失效。完整操作见 `docs/WORKBENCH.md`，本版实际验证见 `docs/WORKBENCH_VALIDATION.md`。

## 传感器位置和起跑方向怎么填

- **车辆 → 传感器前向距离 X / 左向偏移 Y**：填写车上实测的安装距离，以后轴中点为原点，朝车头为 +X、朝车体左侧为 +Y。例如检测中心在后轴前方 60 mm、车体中线上，填 X=60、Y=0；偏右 20 mm 时 Y=-20。本版 X 必须大于 0。
- **场地 → 传感器场地起点 X/Y**：填写传感器起跑时在场地中的坐标，与打卡点共用场地原点。例如起点为 (410,420)，在这里填 410、420。这组坐标与车上的安装距离是不同的数据。
- **场地 → 车头方向角**：直接输入数字，路线图中向右为 0°、向上为 90°、向左为 180°、向下为 -90°；留空时朝向打卡表格第 2 点。
- **车辆 → 前轮转角上限**：按实车可达到的最大偏转角填写。实际路线转角由计算得到，调大上限不能消除倒行或驱动轮反转。

## 重要约定

- 前面一个小转向轮，后面两个大轮，各自独立旋转；按所选驱动侧计算驱动里程。
- 后轴中点为车体原点，车头 +X、车体左侧 +Y。传感器在后轴前方（X > 0）。
- 车头方向角以场地 +X 为 0°、逆时针为正；留空时朝向第二个打卡点。
- 速度为后轴中点恒定地速。传动比是“驱动轮圈数 / 凸轮圈数”，不是电机减速比。
- 凸轮 +1 为逆时针，-1 为顺时针；相位只改变输出几何的起始朝向，装配时必须对准。
- “设计保底基圆半径 + 中位抬升 + 接触半径”决定中位接触中心到凸轮轴的距离。报告另列实际最小半径和转向轴安装坐标。

## 输出文件

| 文件 | 用途 |
|---|---|
| cam.dxf | 毫米、模型空间 1:1 的封闭轮廓与分层参考线 |
| motion.csv | 驱动/后轴里程、时间、目标转角、从动件位移、凸轮角、回算传感器坐标 |
| cam.csv | 整圈理论/实际轮廓坐标、名义转角和压力角，末点重复首点用于闭合 |
| 检查报告.md | 检查结果、假设、主要指标、安装坐标 |
| project.cam.json | 与导出结果对应的项目快照 |

DXF 的 CAM_OUTLINE 是外轮廓，CENTER_HOLE 是中心孔。BASE_CIRCLE、ROLLER_PATH、STEERING_AXIS 是参考层，加工前关闭。轮廓是离散多段线，应在 CAD 中核对采样精度、闭合、孔径及安装关系。

## 凸轮出发点与旋向

「凸轮轮廓」中的红色 **出发点 S0** 对应驱动里程为 0 时的实际轮廓接触点，已包含设置的起始相位；橙色箭头表示凸轮实体的旋转方向。顺逆时针均以正对软件图 / DXF 这一面观察为准，从另一面观察，视觉上的顺逆时针相反。

装车时打开「机构运动」，将进度条拖到最左，按图中的初始机构姿态，让 S0 对准滚子/球接触位置，再固定凸轮与传动轴。图下方显示起跑前轮角，不能一律将前轮摆直；相位已经计入，不要重复叠加。

保留参考图层时，DXF 含 **START_REFERENCE**（S0 出发点）和 **ROTATION_REFERENCE**（CW 顺时针 / CCW 逆时针）标记；这些图层用于装配参考，加工外形仍使用 CAM_OUTLINE。如需刻印，单独安排标记工序。选择「仅轮廓与孔」时不导出参考标记。检查报告记录出发点坐标、旋向和初始前轮角。

## 计算范围

平推模型是导向滑块—固定长度连杆—转向臂销；顶球模型是转向摆臂上的球心圆弧。它们是可配置的理想平面模型，未自动识别 YDI 的销槽或其他空间结构。若实物运动不符，需先调整模型/实测标定，不能只换一个名称就当作精确装配仿真。

检查覆盖打卡顺序、离散名义转向回算、传感器/轮心场地边界、圆障碍物、转角、整圈行程、压力角、曲率过切、接触干涉及单圈容量。轮宽、外壳包络、弹簧力、间隙、惯性、打滑及制造误差尚未计算，仍须实车低速试跑。

## 开发与验证

Python 3.12，Tkinter，NumPy 和 ezdxf。依赖版本记录于 requirements 文件。开发时安装依赖后运行 `python main.py`。打包执行 `python build_app.py --package`，产物与分享包按软件版本命名，保留旧版。

验证使用同一项目工作流入口，包含已知直线算例、曲线路线回算、后轮独立性、摆臂球心圆轨迹、左右置、容量/输入错误和 CAD 回读。运行 `python -m unittest discover -s tests -v`；类型检查 `python -m mypy camtool main.py --check-untyped-defs`。详见“计算模型与验证.md”。

## 独立二次检验

工具栏点“二次检验”，选择最终 `cam.dxf`。可复制当前设计参数作为初值，也可读取项目、保存的检验配置或独立填写实测值。在三个参数页核对车辆、机构、实测装配、来源、起跑姿态和计划运行区间后开始检验。

该系统直接从最终 CAM_OUTLINE 折线反求滚子/球接触和前轮角，再独立积分车辆运动。主程序名义角和可选 CSV 只用于对比。整圈核查机构，只将计划段纳入打卡路线。界面展示路线叠加、逐点偏差、角度曲线、问题位置和三状态判定，可导出含哈希、软件版本、参数快照及已知限制的报告。

参数继承不等于独立测量，需逐组记录数据来源。弹簧力、脱离接触、摩擦、驱动力矩、轮胎打滑、空间包络和实车性能仍为未验证。详细操作和边界见 `docs/VERIFICATION.md`；正式发布的实际验证记录随包交付。
