DESKTOP WORKFLOW

一套可追溯的设计流程

完整参数编辑、优化和独立检验在 Windows 桌面版中使用。

01

输入路线与实车尺寸

按访问顺序设置打卡点，填写轴距、轮径、传感器和机构几何。

02

计算路线与凸轮

将传感器轨迹转换为前轮转角及机构运动，生成实际凸轮轮廓。

03

检查并比较方案

定位超限位置，保留原方案，对比本地优化的五项实际指标。

04

导出并独立反算

导出最终 DXF，再从轮廓求接触和转角，独立积分车辆轨迹。

桌面版实际界面。三视图、打卡进度与当前前轮角共享理论时间轴。
