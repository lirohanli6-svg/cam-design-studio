# 独立二次检验使用与边界

## 操作

1. 在设计页核对参数并计算，导出最终 `cam.dxf`。已加工或改动后的文件应重新检验。
2. 点工具栏“二次检验”。该页面会展开到全宽。选择最终 DXF。
3. 可“复制当前设计参数”（含设计曲线、名义角度作为比较数据），或“读取项目参数”、独立填写数据、读取保存的检验配置。读取项目/配置后不自动猜测计划区间，需核定。
4. 在“车辆与机构”“装配与精度”“路线与来源”三页核对数据。安装转角是驱动角 0° 时，DXF 整体在固定机构平面内的转角，逆时针为正；默认推算值为负的设计廓线相位。实体旋向为正对 DXF 这一面观察的方向。
5. 特别核对固定机构坐标中的转向轴 X/Y、平推导向 X、接触半径、传动比、起跑姿态及运行区间。转向轴 Y 可独立实测，不再只能依赖基圆推算。顶球不使用平推连杆与分支。
6. 搜索转角区间必须覆盖机械限位；区间外可能存在的解未验证。计划段起始姿态是运行区间起始角时的车辆姿态，不会把之前或之后的回程积分进比赛路线。
7. 点“开始二次检验”。依次查看路线、转角、打卡偏差、逐项检查、问题角度、参数与范围。读取可选 motion.csv / cam.csv 时只读角度作比较，不能改变独立回算运动。
8. “导出检验报告”保存报告、结果 JSON、完整参数快照和独立轨迹/接触 CSV。若改动任何检验输入，旧结果失效，须重新检验。

## 独立性

`camtool/verification.py` 不导入主程序的 engine、轮廓生成、名义回算、机构位置函数。共享的只有项目格式和参数定义。解析最终轮廓后，独立求多边形与半径圆盘的外偏置接触边界，枚举偏移线段/顶点圆弧与从动件轨迹的交点，再作全轮廓距离与内外判定，排除穿透、遮挡候选。平推使用摆臂圆与连杆圆相交反解；顶球使用摆臂圆直接求接触。保留搜索区间内全部候选，多解时不偷偷选择“最接近名义角”的分支。

车辆积分只使用反算角、实测轴距/轮距、驱动轮直径、减速比与起跑姿态。名义转角和设计路径只进入独立结果的后续比较。设计项目的基圆、中位抬升、旧 pivot_x / offset 等在参数快照中保留作为来源；真正驱动检验的装配坐标是检验配置顶层的 pivot_x、pivot_y、guide_x 和 install_angle。

## 检查范围

- DXF 毫米单位、XY 平面和 +Z 法向；单一 CAM_OUTLINE、闭合、有限数据、非零边、面积与非相邻边自交/相触。其它图层只作为注记/孔/参考图元忽略，具体名单记录在报告里。
- 完整一圈的接触存在性、多解、全局轮廓穿透过滤、接触点突跳、行程、前轮角限位、接触/传动雅可比接近零的死点。
- 计划段轨迹、逐点访问顺序与偏差、传感器及三个轮心边界、轨迹线段与圆障碍物。没有原设计曲线时，只比较打卡要求，“原路线偏差”明确为未验证。
- 粗细两遍求解：角步长减半、接触残差容差缩至 1/5；比较公共角度的转角与计划段轨迹。解析接触解在公共角处可能完全一致，轨迹稳定性仍由更密集角采样积分另行比较。
- 每项“通过 / 不通过 / 未验证”，不使用总分替代判定。报告中的位置注明局部 DXF、固定机构或场地坐标含义；无法接触时不存在有效接触点，多解列出候选位置。

## 限制

输入是折线近似轮廓；精度复算不增加 DXF 顶点，不证明原始曲线或制造实物的正确性。接触检查与死点检查只覆盖指定搜索角范围和凸轮角采样位置，不构成连续几何严格证明。发现突跳是数值风险信号，不是接触动力学结论。

弹簧压紧力与脱离接触需预紧、刚度、方向、质量、转速及力学模型；摩擦与驱动力矩需摩擦、阻力、传动效率、电机特性和载荷；轮胎打滑需胎地摩擦、载荷与实车试验；轮宽/车壳需三维包络。这些当前均为“未验证”。用户填写“实测”只是来源声明，软件并未核实测量。
