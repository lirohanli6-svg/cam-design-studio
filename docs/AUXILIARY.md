# 必过点、辅助控制与凸轮可行性

适用版本 1.6.0；辅助功能始于 1.5.0。以下均为理论设计与有限采样检查，不能保证加工或实车表现。两类点编辑与地图操作详见 POINT_EDITING.md。

## 操作

1. 「打卡点」仍是比赛必过点，按表格顺序检查。旧项目加载后不改变顺序及打卡要求。原有单元格编辑、独立新增、批量删除、撤销重做和地图拖点继续可用。
2. 在左侧「辅助」页单击 X/Y/所属区间单元格编辑；新增使用独立“新增辅助点”区域，提供 X/Y、区间及添加。支持多选删除、排序、撤销重做和地图添加/拖点。比赛段从起跑位置依次连接必过点；起跑位置与首点相同不重复计段。辅助点用紫色菱形“辅N·段N”标记，不计入打卡数量，不要求曲线穿过。两类点的草稿、选择、新增输入和历史隔离，切页不提交；辅助排序不改所属区间，同段取均值。修改必过点数量或顺序后须重新核对辅助点段号，非法段号会明确报错。
3. 在「场地」填写起跑车头方向、起跑前轮角及转向变化速度规划限值。起跑前轮角与机构中位角不同；限值不代表已验证执行器动态能力。
4. 计算后打开「问题定位」，点击压力角、过切或干涉行。路线与曲线同步定位；接触局部图中绿圆是滚子/球，橙线连到最近轮廓点，红粗线是最近或侵入段，显示间隙与段号。问题属于回程时不标一个虚构比赛位置。
5. 在「优化对比」设置搜索半径、辅助点总上限、候选次数、秒预算和比赛段范围。末段 0 表示直到末段。半径限定在所选必过点连接弦的中点附近，搜索采用法向偏移；这是确定性的有限局部搜索，不是任意空间全局优化。现有辅助点多于上限时先手动减少或提高上限。
6. 点击「搜索辅助点」。后台先按实际比赛段压力/间隙峰值安排优先区间，再轮流覆盖选择范围；预算较小时可能尚未访问所有区间。搜索尝试添加、移动、减少辅助点，以及调整路线切向/张力。原必过点、车辆/机构/凸轮硬件、传动及检查限值保持不变。回程不增加比赛点。
7. 原方案保持有效。结束后查看叠加路线、8 项真实指标和辅助坐标；小窗口中指标表与摘要可滚动。过切余量和间隙越大越好，其他指标通常越小越好。没有改善、预算内无可行解或稳定性未确认均会明确显示。候选搜索预算不含最终精度复算与 DXF 独立检验，它们继续后台执行并可停止。
8. 通过「保留原方案 / 采用优化方案」选择；建议先「保存搜索及检验」，选择空目录保存原项目、候选项目、真正被检的 DXF 原始字节、独立报告及搜索记录。普通「保存两套方案与对比」保存两套输入与指标，不包含完整辅助搜索证据。重新导出或加工编辑过的 DXF 都须重新二次检验，不能套用旧文件哈希的报告。

搜索中可点「停止搜索」；改输入会取消并丢弃过期后台结果。顶端「本地优化」搜索所有内部节点，不再仅前 8 个；顶端「停止计算」管理该任务。「停止搜索」管理辅助搜索。

## 算法与判定范围

路线采用共享弦长参数的整体样条导数，起点结合车头与前轮角确定传感器切向，终点用相邻弦估计导数；通过五次 Hermite 重建共享一、二阶导数。辅助点以端点值、一阶和二阶导数均为零的软形状函数引导本段，默认向引导点位移影响 35%，多个同段引导取均值。曲线保持 C2，但不保证转向变化速度必然满足规划限值；对此单独检查与排名。不是直接对最终凸轮轮廓平滑。

主设计使用同一套采样接触证据检查整圈间隙，局部过切余量为最小凸曲率半径减去 1.01 倍滚子/球半径。负间隙表示侵入，容许离散误差为 max(0.02 mm, 1% 接触半径)。计算后路线步长减半、轮廓点数加倍复算，内部当前最低路线步长 1 mm、最高轮廓点数 4000；触及上限无法同时加密时明确标记未确认稳定。报告列出粗细数值、差值及判定变化。稳定差阈值分别为压力峰值 0.5°、曲率半径 max(0.1 mm, 5% 接触半径)、间隙 0.02 mm；细采样新增不通过会作为失败项。有限采样不是连续几何证明。

搜索先比较主设计失败项数量，再比较压力/过切/接触/转向/打卡/变化率的违规量，最后比较平顺性、压力和长度。搜索中的候选不逐个跑独立检验，最终候选才导出 DXF 重新求解。即使最终独立运动学通过，主设计采样稳定性也可能未确认，界面分别报告。独立器保持自己的轮廓读取、接触、机构反解与车辆积分，不调用主端路线、轮廓或机构函数，不用名义转角作为输入。默认检验角步长由 1° 加密为 0.5°，再以 0.25° 及收紧容差复算；用户仍可独立填写实测装配参数及精度。

剩余回程采用两端短过渡、中间静止导数的回位，避免把比赛终点变化率延长到整个余段造成巨大过冲；比赛/回程接缝匹配位置与一阶变化率，未保证二阶变化率完全匹配。回程仍可能超限或干涉，必须整圈复核。若需要更换基圆、滚子、臂长、传动等，应明确作为实物改造重新测量建模；优化器不会代改。

没有实现弹簧压紧力、脱离接触、摩擦、驱动力矩、空间包络或轮胎打滑，独立报告继续标为未验证。包内案例是构造的理论案例，不是真实采集记录。实际结果见「新版功能验证记录」和「可复现理论案例/辅助点理论案例/实际理论验证结果.json」。

1.5.1会按名义回算误差自动加密到最多4000点，粗细复算比较实际点数而不是请求点数；详细规则与初试验证见 REQUIRED_POINTS.md。
