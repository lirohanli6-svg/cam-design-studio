# 演示、问题定位、优化与数据分析 · 1.3.0

本版在 1.2.0 基础上增加打卡点批量删除并精简重复导航，项目格式仍为 `solar-cam-project` / `version: 1`。程序可离线运行；不需要联网、API 密钥或大模型。两种机构、项目保存、DXF/CSV 导出、S0 标记及独立二次检验继续保留。所有结果页面统一从顶部一排页签进入，四个分析功能只在这里显示一次；点“场地与试跑”返回设计输入。

## 同步演示

点击上方“同步演示”，可直接计算“正常案例”或“问题案例”。两者是固定参数的理论案例；正常案例满足本程序设计检查，问题案例将前轮限位设为 5°、压力角上限设为 15°，并在第 3 个打卡点设置半径 60 mm 圆障碍，能够重复出现转角、压力角和障碍物不满足。

三个画面同时显示场地、小车与传感器、凸轮实体旋转、理想转向机构。时间轴按后轴里程 / 设定速度建立，三个视图使用同一个采样索引。支持播放、暂停、拖动及 0.5/1/2/5 倍速；实际刷新可跨过采样点，暂停或拖动后显示最近的计算时刻。显示当前前轮角、按顺序已完成打卡数、已完成打卡中的最大偏差、到下一个目标的距离（全完成后为终点距离）及不满足项数。“当前目标距离”与打卡偏差分别显示；最终逐点偏差应查看检查/分析结果。

载入案例前，当前项目输入、计算结果、文件路径、来源声明和修改标记保留在内存。“返回原项目”恢复它们；案例不自动保存、不写入原项目文件。退出软件会丢失未保存的内存状态，重要输入请先保存项目。分享包的“可复现理论案例”文件夹也包含这两套项目。

S0 表示固定在凸轮实体上的出发接触点；转向机构中的橙色箭头表示实体旋转方向，仍按正对图中这一面观察。演示按已有理想机构函数绘制；其动画与名义回算不是独立正确性证明，最终轮廓另用“二次检验”复核。

## 问题定位

计算后点“问题定位”，点击检查行。表格显示实际值与限制，下面显示判定依据、适用范围和修改建议；下方三图分别定位比赛路线、凸轮角和相关曲线。红色点/线为定位标记。

前轮最大角、障碍物最短距离、场地越界、最差打卡、回算偏差等可定位到比赛采样位置。压力角、整圈转向/行程、轮廓曲率与接触干涉可定位到整圈凸轮角；若发生在比赛计划段以外，只显示回程凸轮位置，不将它映射成比赛位置。没有有效轮廓或没有可定义位置的检查会明确显示暂无对应位置，不编造坐标。

建议来源于当前检查对应的几何或限值。例如转角过大建议增加过渡空间或核对轴距/传感器偏置，不能仅调大实车限位；障碍问题显示相关轮心/传感器与障碍的最短距离；压力角等建议调整尺度或过渡。修改后必须重新计算、检查及复核最终 DXF，不保证调整后通过。

## 优化前后对比

点击“本地优化”或“优化对比 → 运行本地优化”。计算在后台运行，顶端“停止计算”可停止。优化完成后原方案继续有效，候选不会自动替换输入。

灰色为原方案，红色为优化候选；比较目标传感器路线长度、最大前轮角、整圈最大压力角、最大打卡偏差和不满足项数量，列出候选减原方案的数值。目标路线长度是设计路线长度，不是实测里程。不存在凸轮数据的指标显示“未生成/不可比较”。改善判断只依据可比较的这些指标；指标一升一降显示“存在取舍”，无改善或变差明确显示“未改善”。数值更优不表示实车必然通过。

“保留原方案”或“采用优化方案”是显式选择。采用候选后项目没有原文件路径，须另存为新项目；选择原方案恢复原路径及修改标记。“保存两套方案与对比”输出原方案/优化方案项目 JSON 和含两条轨迹、版本及五项指标的对比 JSON，同名文件存在时拒绝覆盖。

编辑任意设计输入会使该次对比失效。希望日后重用两套方案时，应先保存两套项目。

如果原方案因机构无法达到等原因不能计算，仍允许优化器寻找可计算候选。原输入照常保留和导出，原指标显示“未生成”，没有原路线时不虚构叠加曲线；明确显示“无法判断改善”，必须另行检查候选，不能把缺失原指标当成零或当成改善证据。

## 地图编辑与参数配置

点击顶部“场地与试跑”，在左侧打卡点页勾选“地图编辑”。场地空白处点击添加末尾打卡点；在已有点附近按下并拖动，按下时的坐标映射保持不变，松开算一次修改。点击添加仅接收场地内的点，最大 200 个。拖动可临时移出场地，需计算后查看边界检查。小窗口自动收起“坐标编辑 / CSV”区以保留点表空间；可勾选展开，点击添加或更新也会展开。

表格与图共用输入数据。选中表格行可在 X/Y 框编辑、增删或调整顺序；图中移动同时更新表格与编辑框。撤销/重做保留坐标精度和切线快照；在非文字输入控件中可用 Ctrl+Z/Ctrl+Y。一个项目最多保留 100 次点编辑撤销，打开/新建项目会清空历史。任何几何输入变化均停止播放、撤销旧结果与导出资格；灰色参考折线不是已计算的路线。

批量删除：按住 Ctrl 点击多行，或 Shift 连选；也可点“全选”/在表格中 Ctrl+A。已选数量会显示，点“删除所选”或按 Delete 一次删除全部所选行；剩余点按原顺序重新编号，一次撤销可恢复整批坐标和旧切线，重做可再次删除。“取消”清除选择；未选择时删除不改变项目。更新坐标、上移和下移只允许单选，多选时停用，避免只改动第一行。可全选清空表格，但计算前必须至少补足两个有效打卡点。

车辆与机构页上方固定显示“尺寸示意（非比例）”，点击输入框高亮测量位置。车辆安装尺寸、轮径及驱动侧和机构类型/连杆/摆臂/接触半径属于基础组；速度/转角限位、机构初始角/分支/行程等属于高级组。高级不代表可以忽略，必须与实车一致。

车辆页可保存/加载参数配置，包含车辆、机构、传动比、相位、旋向与来源声明，不含打卡点及场地；加载配置保留路线，旧计算失效。配置格式为 `solarcam-parameter-profile` / `schema_version: 1`。配置来源由用户填写，软件未核实；不是实测时请明确写“未实测”。项目格式保持兼容，配置文件与项目文件应分别保存。

## 实测轨迹 CSV

先计算当前设计，在“实测与扰动”导入真实采集的传感器路径。可保存空格式模板；分享包也有“实测轨迹格式模板_无采样点.csv”。模板没有任何轨迹点，必须替换来源文字并填入采样数据。

CSV 使用 UTF-8（可带 BOM），必须声明：

```text
# unit=mm
# frame=field_xy
# axes=x_right_y_up
# point=sensor
# kind=measured
# source=真实采集设备、日期、记录编号
t_s,x,y
```

单位支持 mm/cm/m，统一换算为毫米；场地 +X 向右、+Y 向上，原点与设计一致；测量点必须为传感器。其他测量点/车体坐标必须由采集人员正确变换后再导入，软件不猜测。`t_s` 是可选的严格递增秒数，`x,y` 必填；2～50000 点、最多 12 MB。不声明 kind 时按用户声明实测处理；测试/理论构造数据必须声明 `# kind=synthetic`，界面及报告明确显示非实测。

蓝色为设计回算路径，绿色为导入路径。按打卡顺序在折线段上搜索最近位置，后续目标不能回用此前采样位置；每点列出偏差及通过/不通过，不能以“路线经过附近”代替顺序打卡。CSV 是一条已记录轨迹，并未验证传感器采集精度、时间同步、来源真实性或场地标定。

改设计后保留原始导入数据，但清除旧偏差；重新计算后需“重新比较实测”。导出分析 JSON 包含版本、项目快照、文件来源、SHA-256、原始轨迹与时间、逐点偏差，和独立标记的理论扰动结果。

## 理论扰动分析

设置驱动轮有效直径相对变化上下限（百分比）、安装相位增量上下限（度）、每组 2～7 个采样值、角步长。支持轮径 ±30%、相位 ±90°，实际角步长还须符合二次检验器的精度约束。基线始终计算一次，零增量不会重复计算。

一次分析仅导出一次当前名义最终凸轮，然后固定这份 DXF，通过独立二次检验的轮廓→接触→前轮角→轨迹链分别改变实车驱动轮径或安装角。正相位增量沿二次检验装配坐标中逆时针正角方向定义；不是重新设计一片更适合新参数的凸轮。计划运行凸轮角区间固定，轮径变化相应改变行驶距离。顶端设置的是采样范围，不是已知制造误差或实测分布。

输出每个方案的理论路径、最大打卡偏差及相对基线变化、不通过与未验证项数，保存本次轮廓哈希、粗细角步长和逐项检查。点击一行可单独突出该预测；检查失败的方案仍保留，不因失败而丢掉不利结果。改变范围会使旧扰动结果失效。

这是单因素扫描，不是多因素联合最坏情况、统计置信度、连续公差证明或动力学仿真。弹簧/接触力、摩擦、驱动力矩、轮胎打滑及实车性能仍未验证。分析支持停止，过期结果不会覆盖新输入。
