# 场地与凸轮细节查看 · 1.7.0

本功能只改变显示，不修改项目坐标、单位、硬件尺寸、计算结果、凸轮轮廓或导出比例。主界面“场地与试跑”和“凸轮轮廓”提供同一套视图工具；独立二次检验仍在原页面执行。

## 缩放、平移与查看

- 鼠标滚轮以光标所指世界坐标为锚点缩放，放大后该位置保持在光标下；中键拖动平移。X/Y始终等比例，路线和凸轮不拉伸。
- “放大”“缩小”以当前画面中心缩放；“适应全部”按当前有效图形重新建立全图范围；“恢复视图”返回本项目/该窗口最近建立的全图范围。缩放范围5%～51200%，100%是当前窗口中的全图基准，不代表屏幕实物1:1。
- 坐标轴、网格、数值和毫米比例尺随视图更新；悬停显示光标世界坐标。选择打卡点显示坐标及当前有效名义偏差，修改后偏差显示未验证；辅助点显示区间，不计打卡。
- “放大查看”打开可调整大小、可最大化的独立窗口。主图与每个窗口分别保留自己的观察中心和缩放，共享当前数据、点选择、编辑类型及播放进度。改变窗口大小保留世界中心和相对缩放比例。
- 播放、暂停、拖动时间轴、选择问题不会重置观察视图。“问题定位”页的“定位并放大”是显式操作，会把相应路线位置及凸轮接触区带到视图中心；回程问题只定位凸轮，不虚构比赛位置。
- 打开/载入整个项目时重置观察视图；视图状态不写入项目文件。放大没有生成更密的工程数据，折线细节仍受实际计算采样限制。

## 浏览与编辑

“浏览模式”中滚轮缩放、中键或左键拖动平移，不会添加或移动点位。“编辑点位模式”保留左键点位选择、拖动、空白添加及表格联动；中键仍用于平移。左侧原有地图编辑勾选框与此模式同步。

点位类型选择“打卡点/辅助点”与浏览/编辑是两件事：前者选择哪一类列表，后者决定能否修改。主图上方及放大窗口可明确选类型。蓝圆和编号是打卡点，紫菱“辅N·段N”是辅助点；两类列表、草稿和历史独立。辅助地图新增仍使用独立新增区的所属区间。

放大后拖动不改变坐标约定。按下选点时锁定这次手势的坐标变换，并捕获鼠标；连续移动合并为最多约每16ms一次的预览，表格只更新对应行。松开时立即处理最终位置，包含拖出画布/窗口后的松开，释放捕获；辅助点超场地的非法位置明确拒绝，不自动吸附。

一次完整拖动只记一条历史。单击无位移、拖回按下位置不记历史；首尾同坐标可从表格先选末行，再拖该编号，首行不会一起移动。拖动中修改一次即使旧结果/导出失效并取消后台计算，后续预览不反复运行全量失效流程；过期结果不能覆盖新坐标。回到原坐标虽不记历史，曾失效的结果仍需重新计算。

## 凸轮接触细节的含义

凸轮轮廓图使用凸轮自身坐标显示最终制造轮廓，旋转中心、S0和旋向保留。滚子/球、最近接触样本和最近/侵入段按当前驱动角换算到同一凸轮坐标；不是另一份实体旋转动画。原“机构运动”和“同步演示”的旋转动画继续保留。

绿色圆是滚子/球；红点是已有主端采样中距其中心最近的轮廓点；负间隙显示对应最近段。细节文字显示最近样本的驱动角、压力角和间隙，并标记“主端采样”；这不是独立二次检验结果，也不是全部多解/侵入段的连续几何证明。没有当前结果或证据时明确未验证，动力学/实车仍未验证。

## 性能与验证边界

绘图复用Canvas对象，只更新变化的坐标/属性，移除不再需要的对象，不反复清空画布；坐标轴/网格及视图保持稳定。拖动不调用路线/凸轮计算，数学数据与导出尺寸不变。工程计算仍需显式后台启动并可取消。

本机真实界面与Windows鼠标捕获验证、清空次数、表格重建次数及性能数据见“新版功能验证记录”和“发布验证.json”。不是所有显卡、远程桌面或负载下的无卡顿保证；很密的图形、高倍缩放、同时打开多个窗口仍增加绘制成本，未保证固定帧率。Tk窗口绘制仍在主线程，事件合并会跳过中间鼠标样本，但松开最终坐标准确保留。
