# 两类点的独立编辑 · 1.6.0

打开“场地与试跑”，在左侧选择“打卡点”或“辅助”。正常切换页面保留各自未提交内容和选择，不会自动添加或提交。新建、打开项目或明确采用另一方案会载入整套项目，重置两类编辑历史。

## 编辑和新增

- 编号列选行；单击 X/Y 单元格开始编辑。辅助点的“所属区间”也可单击编辑。蓝色是选中行，黄色带边框的格是编辑草稿。
- Enter 提交；Esc 取消当前格；Tab/Shift+Tab 校验、提交当前格后向后/向前换格，辅助表按 X→Y→所属区间循环。单击另一格前需先提交或取消有变化的草稿。无变化和取消不记历史。
- 空值、非数字、NaN、无穷值被拒绝，草稿保留；辅助坐标须在当前场地范围内，区间须为有效整数。错误显示在表格下方或新增字段旁，不自动截断、纠正或删除。
- “新增点位”和“新增辅助点”分别拥有自己的输入。选行、编辑或拖点不会填入它们。辅助点使用 X/Y、所属区间和“添加”；表格中没有“修改所选”按钮。
- 辅助区间从起跑位置依次连向必过点；起点与第一个必过点相同时不重复计段。例如初试文件的区间1为必过点1→2，区间2为2→3。修改必过点顺序/数量或起点后，需要自行核对辅助点区间，软件不会重排或重映射另一类点。

## 选择、删除、排序与历史

编号列支持 Ctrl 多选、Shift 连选；全选按钮/Ctrl+A 和 Delete/删除支持批量删除。“取消”清除当前表的选择；取消草稿使用 Esc。

上移/下移支持单点或选中的多点块。打卡点行序决定比赛访问顺序。辅助点显示顺序不参与形状计算，整行移动时所属区间随该点保留；同区间多个辅助坐标取均值引导该段。辅助点不计入打卡数量，不要求曲线经过，也不能替代必过点。

有效编辑、新增、批量删除、排序或完整地图拖动分别记一条历史。两页撤销/重做各自生效；Ctrl+Z/Ctrl+Y 在当前点页或场地图的当前模式中作用于对应类型。输入框获得焦点时不会触发另一类列表撤销。另一个页面有草稿时，仍可以独立修改、撤销本页；保存、计算、导出、搜索和采用方案等整项目操作会提示先用 Enter/Esc 明确处理草稿。

## 地图

地图上方显示当前“打卡点/辅助点”模式；切换左侧点页同步模式，地图模式下拉框也可切换相应点页。勾选地图编辑开关后，空白处点击添加当前类型，点击已有点选中、高亮并显示编号，拖动编辑当前类型。点击另一类点所在位置不会误添加或修改，需先切换模式。

蓝圆与数字表示打卡点；紫色菱形“辅N·段N”表示辅助点；粗外框及“选中辅N”表示选中辅助。表格与地图选择双向同步，各自选择可保留。首尾同坐标打卡点仍分编号保留；重叠时拖动当前已选编号的点，可先从表格选择。

地图添加辅助点使用独立新增区里的“所属区间”，不会复用或覆盖新增 X/Y 草稿。拖动改变 X/Y、保留所属区间；超出辅助场地边界的位置被拒绝而非自动吸附。一次拖动到松开鼠标只记一条历史，单击选择或数值未变不记历史。

任意类型发生有效修改，都会标记项目已更改，使旧计算、比较候选及相关导出失效，并取消/丢弃过期后台结果；请重新计算。搜索不会自动采用候选；需在“优化对比”明确点“采用优化方案”，或选择“保留原方案”。

## 保存与工程限制

保存会保存两类列表，兼容 schema 1。旧文件 `waypoints` 继续全部是比赛必过点，缺失的 `auxiliary_points` 按空列表加载。打开项目不改写原文件。

辅助点是形状控制，不保证改善压力角、过切、干涉或打卡结果。最终方案仍须检查主端报告，并从实际导出 DXF 做独立二次检验；软件未完成实车动力学或试跑认证。“初试”原项目仍有已知设计失败，不能因编辑功能通过而声称该项目通过。
