## 本轮修改

- 打卡点改为多选，支持 Ctrl 不连续选择、Shift 连续选择、全选 / Ctrl+A、删除所选 / Delete、取消选择及所选数量。
- 批量删除保持剩余顺序与序号，一批对应一次撤销记录，可恢复整批精确坐标与旧切线，支持重做；旧计算、对比、分析及导出资格失效。
- 多选时停用只适用于一行的坐标更新和上下移动，避免静默只操作第一行；未选择时删除不修改项目。
- 原重复按钮和内容页签合并为顶部统一导航，四个分析入口各只显示一处。内容区保留原页面与切换逻辑；11 个顶部页签在 1000×640 下可见并可点击。
- 小窗口自动收起坐标/CSV 详细编辑区，保留点表与批量操作；可勾选展开，添加/更新操作也会提示并展开。
