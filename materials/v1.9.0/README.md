## 老师现场审核操作

1. 点击“示例与路演”打开正常理论案例。演示尺寸应替换为实测值；本材料为可复现压力角案例，仅把基圆设为25mm。
2. 打开“检查报告→设计改进助手”（或标签“改进助手”），等待自动诊断。无需授权即可看到压力角49.937214°>45°，发生在比赛运行段、凸轮0°、路线(300,400)mm。
3. 区分已确认事实与待验证原因。确认可改部件：本例仅选择凸轮尺寸允许改变，明确勾选允许相关安装位置联动，其余硬件固定。
4. 保留22.5～40mm探索范围。高级设置把整体秒预算设为180秒后开始实际试算。此范围没有实测机械依据，不是安全范围。运行耗时取决于电脑，老师可同时查看已导出的结果。
5. 查看40mm候选：主检查、采样复核及实际DXF独立审计通过；压力角降到41.224371°。只预览时原案不变，点击采用才更新，可撤销。
6. 核对安装代价：转轴Y−38→−23mm、中位接触Y42→57mm、轮廓宽×高79.784×83.705→109.653×113.673mm，行程跨度6.997mm不变。
7. 导出方案与证据，检查最终DXF哈希。保持名义打卡、完整设计、最终DXF、实车四层状态分别展示。

## 本轮如实记录

完整130项首轮：128通过，1失败、1错误；两项均使用同一成功路径夹具，90秒预算内未生成独立审计。单线程16项重试仍是相同两项。仅把该测试夹具的完成审计预算90→300秒，重新运行助手16项；实际结果见validation.json。没有调整软件默认60秒、采样/工程门槛或测试断言，原1秒超时与取消测试保留。夹具调整后没有再次运行完整130项，不能写成一次全量通过。此前本地构建的130项通过属于历史轮次。

默认60秒的一次重跑在独立审计完成前耗尽，主检查通过的候选仍显示独立验证未完成，没有把它写成通过。为完成本次展示，明确改为180秒；实际做了3次单参数试算，40mm候选完成独立检验，其他未完成/不通过候选保留。180秒整体预算仍耗尽，不代表全部候选验证完成或不存在其他可行方案。

测试与GUI证据属于本机软件检查；本地EXE构建轮次曾出现一次原生窗口外拖动失败，同一EXE完整重试通过，原因未确认。没有第二台电脑、实车轨迹、制造装配、动力学或连续几何证明。独立流程也可能共享模型假设；不能把理论偏差称为实车精度。

AI用于开发辅助；软件运行时是确定性工程计算与有限数值搜索，未调用大模型。旧在线网页及v1.3.0附件仍是历史版本。本次不上传v1.9.0 Windows EXE/ZIP、不改网站。
